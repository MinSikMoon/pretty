# ⚖️ Pretty Law

**법령 조문을 고르면, 그 조문을 구체화한 시행령·시행규칙·감독규정·고시·세칙 조문이 한 화면에 이어서 나옵니다.**

법 → 시행령 → 규정으로 이어지는 위임 구조를 조문 단위로 따라가 보는 뷰어입니다.
"이 조문의 세부 기준이 어느 규정 몇 조에 있지?"를 찾아 여러 창을 오가던 일을 줄이려고 만들었습니다.

> 🚧 시험판입니다. 연결은 규칙 기반 자동 추출이므로 **참고용**이며, 법적 효력이 있는 정본은 [국가법령정보센터](https://www.law.go.kr)입니다.

## ✨ 이런 걸 할 수 있어요

### 🔎 조문 하나로 상하위 조문 펼치기
조를 고르면 그 조문과 이를 인용·구체화한 하위 규정 조문이 나란히 펼쳐집니다.
항·호·목 **줄 단위**로 연결되어, 해당 항을 구체화한 하위 규정만 골라 볼 수 있습니다.

### 🧵 연결 경로를 선으로 확인
줄을 누르면 법 → 시행령 → 규정으로 이어지는 **인용 경로만** 굵은 선과 하이라이트로 표시됩니다.
시행령을 건너뛰고 규정이 법을 직접 인용한 경우는 점선으로 구분합니다.

### 👀 세 가지 보기
- 🧭 **탐색**: 고른 조를 중심으로 하위 규정을 따라 들어갑니다. 기본 화면입니다.
- 🗺️ **계보**: 법 | 시행령 | 규정을 3단으로 나란히 놓은 전체 지도입니다.
- 📖 **읽기**: 고른 항을 가운데에 크게, 상위는 왼쪽·하위는 오른쪽에 보여 줍니다.

### 📌 근거 문구
하위 규정이 "법 제19조에 따라…"처럼 상위 조문을 인용한 **그 문장**을 표시합니다.
왜 연결됐는지 직접 확인할 수 있어, 연결을 맹신하지 않고 검증할 수 있습니다.

### 💬 본문 속 인용 미리보기
"영 제16조제3항제4호" 같은 인용을 누르면 그 조문을 말풍선으로 미리 보고, 말풍선 안의 인용도 이어서 따라갈 수 있습니다.
"같은 법 시행령", "이 영" 같은 지시어도 문맥에 맞는 법령으로 해석합니다.

### 📎 별표·서식
조문 끝의 `▤ 별표` 칩으로 해당 별표를 열고, 호·목이 지정된 인용은 그 항목으로 바로 이동합니다.

### 🗓️ 어떤 버전의 법인지 표시
`⋯ 더보기 → 법령 버전 정보`에서 법령별 **공포번호·공포일·시행일**을 확인할 수 있습니다.

### 🔽 위임 표시
줄 끝의 `▼숫자`는 그 줄의 위임을 받아 구체화한 하위 규정 수, `▽숫자`는 위임 문구 없이 하위 규정이 언급한 수입니다.

### 🎨 읽기 편한 화면
- 괄호 깊이별 색 표시
- 다크 모드
- 용어 사전
- 선택한 조문과 상하위를 **통째로 복사**하는 기능

### 📋 프롬프트 만들기
고른 조문과 상하위 조문을 묶어 AI에게 물어볼 질문 형태로 만들어 복사합니다.
Pretty Law 자체는 AI를 쓰지 않으며, 복사한 글을 어디에 붙여 넣을지는 사용자가 정합니다.

## 🔒 개인정보와 작동 방식
- 서버 없이 브라우저에서만 동작하며, **입력한 검색어나 선택 내용을 수집하지 않습니다.**
- 연결은 법령 본문의 인용 문구를 규칙으로 읽어 만든 것이며, 생성형 AI가 만든 것이 아닙니다.
- 글꼴(Inter·Pretendard)은 외부 CDN에서 받아 옵니다. 막힌 환경에서는 기본 글꼴로 바뀌며 기능은 같습니다.
- 조문 제목 옆 `?` 버튼은 누르면 구글 AI 모드를 **새 탭으로** 엽니다(누르기 전에는 외부 전송 없음).

## ⚠️ 알려진 한계
- 자동 연결이라 **누락·오연결이 있을 수 있습니다.** 중요한 판단은 근거 문구와 정본으로 확인해 주세요.
- 일부 규정은 hwp·pdf에서 글자를 읽어 와 띄어쓰기 오류로 인용을 놓칠 수 있습니다.
- 별표는 추출한 텍스트라 표 모양이 깨질 수 있습니다.
- 법령은 개정되므로 화면의 **공포·시행일**이 지금 기준인지 확인해 주세요.
- 개발 환경은 Chromium 계열이며, Edge·Safari 등에서 화면이 다르게 보일 수 있습니다.
